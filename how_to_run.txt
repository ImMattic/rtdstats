RTD Stats - How to Run Locally

Prerequisites:
- Docker and Docker Compose
- Python 3.11+
- Node.js 20+

1) Set up environment variables
- The repo root now includes a ready-to-use .env file.
- Review the values if you are not using the defaults.
- If you ever want to reset it, copy .env.example back over .env.

2) Start the infrastructure and apps
- From the repo root, run:
  docker compose up --build

3) Apply backend database migrations
- In a second terminal, run:
  docker compose exec backend alembic upgrade head

4) Open the app
- Frontend: http://localhost:3000
- Backend health check: http://localhost:8000/health

5) Optional backend-only run
- If you want to run without Docker, start PostgreSQL/TimescaleDB separately.
- Export DATABASE_URL from .env.
- Install Python dependencies from requirements.txt.
- Run migrations with Alembic.
- Start the API with:
  uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Notes:
- The backend polls the GTFS-RT feeds automatically on startup.
- The live map uses Leaflet and will update on a polling interval.
- Google Maps traffic integration is not enabled yet.
